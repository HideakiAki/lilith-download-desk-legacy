## Cutoff

**v1.3.2 is the final archived legacy version.** The browser overlay's inability to be minimized or dismissed, and the possibility that it overlaps website controls, are known limitations. There is no overlay fix in these snapshots.

## Downloading older versions

Open the [Legacy Archive GitHub Release](https://github.com/HideakiAki/lilith-download-desk-legacy/releases/tag/legacy-archive-v1.3.2), expand **Assets** if necessary, and select the ZIP for the desired version. The repository root holds the v1.3.2 source. To inspect earlier versions, download and extract their ZIPs. The ZIPs were removed from the current `main` source tree, but remain in prior Git commits.

These are prototype archives, not verified stable releases. Versions are listed from oldest to newest for historical clarity.
