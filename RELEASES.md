# Releases and Version History

This repository contains **six original ZIP packages** (byte-for-byte copies of the packages recovered for this archival build). These packages preserve the earlier releases. **Uploading through the GitHub website does not create Git tags or restore old commit history.**

| Version | Original download | Historical milestone |
|---|---|---|
| `v1.0` | [`Lilith_Download_Desk_v1.zip`](release-archives/Lilith_Download_Desk_v1.zip) | Initial Windows/Tkinter download queue prototype |

## Cutoff

**v1.3.2 is the final archived legacy version.** The browser overlay's inability to be minimized or dismissed, and the possibility that it overlaps website controls, are known limitations. There is no overlay fix in these snapshots.

## Downloading older versions

On GitHub, open an archived ZIP in `release-archives/`, then use the file download action. The GitHub website upload contains the v1.3.2 source at the repository root. To inspect earlier versions, download and extract the corresponding ZIP.

These are prototype archives, not verified stable releases. Versions are listed from oldest to newest for historical clarity.
